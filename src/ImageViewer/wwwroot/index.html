🖼️ 查看器
开启后，查看图片时点右键立即关闭查看器；关闭此开关后，右键可继续拖拽平移图片。
⚡ 极速查看器 Beta
开启后，双击被关联的图片格式立即进入原生极速查看器（仅旋转 / 缩放 / 平移）。点「回到相册」才加载主界面。

🔍 识别功能
关闭后隐藏右键菜单的「识别角色」、工具栏的「一键识别」和查看器的「识别」按钮，识别相关功能不可用。
角色识别 API 地址：右键「识别角色」和「一键识别」用它识别图片中的角色。点「应用」保存。
✏️ 图片编辑
查看器「✏️ 编辑」按钮用哪个软件打开当前图片。留空自动使用画图（mspaint）/ Paint.NET。
若系统没有画图（如精简版 Windows），请在此填写你常用的图片编辑软件路径，点「应用」保存，编辑按钮将用它打开。
📂 文件关联
勾选格式后点「应用」：图片会加入本软件的「打开方式」。要设为双击默认打开：右键任意图片 → 打开方式 → Hoping Image Viewer → 勾选「始终使用此应用」。
