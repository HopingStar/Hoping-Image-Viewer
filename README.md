# 🖼️ Hoping Image Viewer

一款 **Windows 本地图片查看器**：桌面窗口应用，支持浏览本地相册、图片标签管理、GIF 动图、平滑缩放 / 旋转 / 导出，以及**角色识别**（AI 自动识别图中角色）。

- ✅ 支持 **Windows 10 / 11（x64）**
- ✅ 双击即用，无需浏览器、无需联网
- ✅ 绿色便携：数据保存在程序目录内，可整体拷贝

---

## 功能特性

- 🗂 **相册浏览**：按文件夹分组成相册，点相册卡片进入专属图片页；「🏠 首页」一键回到相册页
- 📁 **添加相册文件夹**：链接你任意位置的图片文件夹（**只记路径，不复制、不移动你的图片**），重启自动加载
- 🏷 **图片标签**：右键图片即可添加 / 移除标签（当前图已有标签紫色高亮）；「🏷 标签」页可新建 / 删除标签、**多选标签交集筛选**图片
- 🔍 **标签搜索**：右键「添加标签」弹出子菜单，顶部搜索框实时过滤，快速定位
- 🤖 **角色识别**：识别图中角色，显示候选与置信度，**一键把角色加为标签**
- ⚡ **一键识别相册**：自动逐张识别整个相册 → 预览核对（可修改识别错的标签）→ 确认后才写入标签
- 🖱️ **拖入图片**：把图片直接拖进窗口即可查看
- 🎞️ **GIF 动图**：支持 GIF，**缩略图也是动图**
- ☰ **列表视图** / 🗂 **平铺视图** 自由切换
- 🗂 **图片排序**：按**名称 / 类型 / 修改时间 / 创建时间 / 大小**排序，支持升序 / 降序；**每个相册单独记忆**你的排序偏好
- 🌐 **多语言**：设置页可切换 简体中文 / English / 繁體中文 / 日本語 / 한국어 / Русский / Français / Deutsch（共 8 种语言，每项带国旗），默认跟随系统语言（未匹配则回退简体中文）
- ⚙️ **文件关联**：设置页勾选图片格式并应用，双击该格式的图片文件即可用本软件打开
- ⚡ **极速查看器**：设置中开启后，双击被关联的图片格式**秒开**原生极速查看器（仅旋转 / 缩放 / 平移，不加载主界面）；点「回到相册」才进入主界面
- 🖼 **多格式支持**：jpg / jpeg / jfif / jpe / png / bmp / gif / webp / tif / tiff / ico
- 🏷 **版本标识**：窗口标题栏显示当前版本号（如 v1.0.1）
- 🔍 **平滑缩放**：图片未超出窗口时**以中心缩放**，超出后**以鼠标为中心**缩放（滚轮、按钮、双击）
- ✋ **平移**：放大后按住鼠标拖拽
- ↻ **旋转与导出**：左右 90° 旋转实时预览，「保存」导出旋转后的图片
- ◀▶ **快速切换**：按钮或键盘 ← → 遍历相册全部图片
- 🚀 **流畅浏览**：上万张的相册也能秒开、不占内存（网格虚拟化渲染）

## 下载与安装

适用于 **Windows x64**。两种方式任选：

### 方式一：直装版（zip 便携版）

- 解压后双击 `HopingImageViewer.exe` 即可使用，**无需安装**
- 绿色免安装，数据保存在解压目录内 `data/`
- 可把整个文件夹拷到 U 盘 / 其他电脑直接运行

### 方式二：安装程序

- 启动后**可选择安装路径**
- 勾选「**绿色安装**」：便携模式——不创建卸载程序 / 注册表 / 快捷方式，整个文件夹可拷贝带走
- **不勾选**（普通安装）：创建**卸载程序**、开始菜单快捷方式（可选桌面快捷方式），可在控制面板卸载；**卸载时询问是否删除程序数据**（默认保留）

## 快速上手

1. 打开软件（直装版双击 exe；安装版从开始菜单 / 桌面启动）
2. 首次使用点「📁 添加文件夹」，浏览并导入你的图片文件夹
3. 相册页点相册卡片 → 进入图片页浏览
4. 右键任意图片 → 打标签 / 识别角色

| 操作 | 方式 |
|---|---|
| 添加相册文件夹 | 顶部「📁 添加文件夹」→ 选择任意图片文件夹（直接链接，不复制） |

| 平铺 / 列表 | 打开相册后右上角「🗂 平铺」「☰ 列表」切换 |

| 切换语言 | 「⚙️ 设置」→「🌐 语言」→ 选语言即可即时切换并保存 |
| 文件关联 | 工具栏「⚙️ 设置」→ 勾选格式 → 「应用」 |
| 极速查看器 | 「⚙️ 设置」→ 勾选「极速查看器」→ 双击关联图片秒开；点「回到相册」进入主界面 |
| 打开图片 | 平铺视图点缩略图 / 列表视图点行 |
| 放大 / 缩小 | 鼠标滚轮、➕➖ 按钮 |
| 平移 | 放大后按住鼠标拖拽 |
| 旋转 / 导出 | 「↺ ↻」旋转，「💾 保存」导出旋转后的图片 |
| 打标签 | 右键图片 →「添加标签」→ 点标签（或输入新标签名） |

## 角色识别（AI）

「识别角色」与「一键识别相册」需要调用一个**角色识别服务**（AI 模型）：

1. 先在本机运行一个角色识别服务（例如 角色识别 API ，默认地址 `http://localhost:5000`）
2. 打开任意图片 → 查看器「🔍 识别」→ 面板顶部填入服务地址 → 点「保存」
3. 即可识别图中角色，并把角色一键添加为标签

> 识别服务未配置时，点「识别」会提示配置地址；地址保存在程序目录 `data/ai.json`。

## 数据与隐私

- 所有数据（相册链接 / 图片标签 / 排序设置 / 识别配置）保存在**程序目录下的 `data/` 文件夹**，纯本地、不上传任何内容
- 便携版 / 绿色安装：数据随程序目录一起，拷贝文件夹即携带数据
- 移除相册链接不会删除你的图片文件

## 常见问题

| 问题 | 解决 |
|---|---|
| 图片打不开 / 列表里没有 | 仅支持 jpg / jpeg / jfif / jpe / png / bmp / gif / webp / tif / tiff / ico；损坏文件会被跳过 |
| 想换位置 / 换个电脑 | 直装版 / 绿色安装直接拷贝整个文件夹；普通安装请重装并迁移 `data/` |
| 角色识别提示连不上 | 确认角色识别服务已启动、识别面板里地址填写正确（如 `http://localhost:5212`） |
| 标签太多找不到 | 右键「添加标签」子菜单顶部搜索框输入关键词过滤 |

## 已知限制

- 仅限本地使用，无账号系统
- 缩略图统一为 JPEG（透明 PNG 缩略图会带底色）
- 首次打开超大相册时，扫描统计可能略慢，但页面会先显示首屏
